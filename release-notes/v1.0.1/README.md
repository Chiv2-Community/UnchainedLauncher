# Unchained Launcher v1.0.1

- Fixed settings and enabled mods not being remembered after closing the launcher.
- Fixed repeated downloads and duplicate copies of installed mods.
- Fixed mod installation failures caused by missing signature files.
- Fixed mods being left in old folders when upgrading the launcher.
- Fixed repeated prompts for manually installed mods you chose to keep.
- Fixed server mod selections becoming outdated after mods were updated or disabled.
- Fixed server restarts trying to load mods that were no longer available.
- Fixed scrolling getting stuck over text, dropdowns, and nested lists.
- Fixed mod cards resetting when enabling or disabling mods.
- Fixed mod confirmation windows being too small to read comfortably.
- Fixed hard-to-see checkboxes and blurry content in mod cards.
- Fixed the launcher continuing after you cancelled a launch.
