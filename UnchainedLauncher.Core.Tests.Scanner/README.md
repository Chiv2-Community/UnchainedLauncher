# Portable scanner/cache tests

Run on .NET 10:

```sh
dotnet test UnchainedLauncher.Core.Tests.Scanner/UnchainedLauncher.Core.Tests.Scanner.csproj
dotnet test UnchainedLauncher.PakScannerApp.Tests/UnchainedLauncher.PakScannerApp.Tests.csproj
```

Links Core visibility, cache, recovery-progress, recovery, mutation-safety and config-persistence tests against production Core. Reuses Core's existing friend assembly name. `PORTABLE_SCANNER_TESTS` excludes only the recovery suite's GUI release-link test; that test remains enabled in the Windows suite.

Conversion/restart cache data is synthetic, generated by the unchanged v1.0.2 production writers. `TestData/ModManagerV3.json` is an actual released preference fixture, not a captured full-scan cache. No captured user cache JSON is supplied.

Real-registry ownership cases link the windowless production `RegistryReleaseFormVM` with its normal MVVM/Fody setup. The harness does not reference WPF or the GUI assembly.

Cache reuse compares filenames, lengths, and modification timestamps. Same-length changes preserving timestamps are not detectable. Cached scan dependencies do not grant ownership or permission to retain unmanaged paks.
