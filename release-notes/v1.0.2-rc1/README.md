# Unchained Launcher v1.0.2-rc1

Prerelease for testing; v1.0.1 remains the latest stable release.

- Fixed installer Back navigation, installation selection, and failure recovery.
- Fixed installation discovery when one store's metadata cannot be read.
- Fixed local mod actor visibility and made scan results more consistent.
- Improved scan-cache reuse after unrelated mod changes and pak-hashing logs.
- Fixed the Epic Games launcher exiting before the game finished.
- Improved progress-bar contrast and dark-mode settings styling.

[Changes since v1.0.1](https://github.com/Chiv2-Community/UnchainedLauncher/compare/v1.0.1...v1.0.2-rc1)
